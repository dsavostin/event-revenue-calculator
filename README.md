# Калькулятор гонорара

Автоматизированный Excel-калькулятор для расчёта финансовой модели музыкального мероприятия.

Инструмент помогает быстро определить, как распределить гонорар между музыкантами и другими участниками мероприятия с учётом транспортных расходов, амортизации автомобилей, комиссий и дополнительных выплат.

Проект построен как прикладной рабочий инструмент для расчёта экономики выступлений.

## 🎯 Бизнес-задача

При расчёте гонорара за мероприятие необходимо одновременно учитывать несколько переменных:

* общий гонорар;
* количество музыкантов;
* дополнительные блоки выступления;
* оплату сессионного музыканта;
* работу звукорежиссёра;
* агентскую комиссию;
* транспорт;
* километраж;
* расход и стоимость топлива;
* амортизацию автомобилей;
* резервный фонд.

При ручном расчёте большое количество параметров увеличивает риск ошибок и делает пересчёт каждого нового мероприятия неудобным.

Задача проекта — автоматизировать этот расчёт и свести его к заполнению нескольких входных параметров.

## 📊 Что делает калькулятор

Пользователь задаёт параметры мероприятия, после чего калькулятор автоматически рассчитывает:

* транспортные расходы;
* стоимость ГСМ;
* агентскую комиссию;
* оплату звукорежиссёра;
* оплату сессионного музыканта;
* выплату каждому музыканту;
* общую сумму выплат музыкантам;
* сумму, остающуюся в фонде;
* контроль распределения всего гонорара.

Калькулятор поддерживает два режима распределения:

**Стандартный**

Основная часть доступного бюджета распределяется между музыкантами, при этом формируется резервный фонд.

**Поровну**

Все участники, участвующие в распределении, получают одинаковую долю с учётом заданных условий.

## ⛽ Автоматизация стоимости топлива

Стоимость топлива не задаётся вручную в основном калькуляторе.

В отдельном листе `GSM_PRICES` используется импорт данных с внешнего сайта через `IMPORTHTML`.

Источник данных:

`https://driff.ru/fuel-dynamics/tula/`

Из таблицы с ценами автоматически используются актуальные значения для:

* АИ-92;
* АИ-95;
* АИ-98;
* дизельного топлива;
* газа.

Это позволяет учитывать изменение стоимости топлива при последующих расчётах без ручного обновления каждой строки.


## 🚗 Расчёт транспортных расходов

Для каждого автомобиля задаются:

* тип топлива;
* средний расход;
* стоимость топлива;
* амортизация на километр.

На основе этих параметров рассчитывается стоимость поездки.

Общая логика:

**ГСМ + амортизация = стоимость автомобиля на заданный километраж**

Результат округляется до удобной для работы суммы.

Также предусмотрена возможность указать второй автомобиль или использовать заказной транспорт.

## 💰 Распределение гонорара

После расчёта обязательных расходов калькулятор определяет доступную сумму для распределения.

Учитываются:

1. транспортные расходы;
2. агентская комиссия;
3. оплата звукорежиссёра;
4. оплата сессионного музыканта;
5. выплаты основным музыкантам;
6. резервный фонд.

Для выплат музыкантам используется округление до 1 000 ₽.

Оставшаяся после распределения сумма автоматически определяется как фонд.

## 🔎 Контроль ошибок

В калькулятор встроены проверки корректности расчёта.

Проверяется:

* минимальный гонорар;
* наличие заданного километража в таблице транспортных расходов;
* корректность распределения денежных средств;
* отсутствие отрицательного фонда;
* соответствие итоговой суммы исходному гонорару.

Контрольная формула проверяет, что:

**гонорар − все расходы − все выплаты − фонд = 0**

Если условие выполняется, калькулятор показывает статус `OK`.

Это позволяет использовать таблицу не только как калькулятор, но и как инструмент контроля финансового расчёта.

## 📁 Файлы проекта

### `calculator/royalties-calc.xlsx`

Основной рабочий файл с калькулятором.

Содержит три листа:

* `Калькулятор гонорара` — основной интерфейс расчёта;
* `GSM` — справочник автомобилей, расхода топлива, амортизации и стоимости поездки;
* `GSM_PRICES` — импортируемые цены на топливо.

### `docs/project_description.md`

Описание бизнес-задачи, структуры расчёта и логики автоматизации.

## 📌 Результат

Вместо ручного пересчёта нескольких десятков параметров пользователь заполняет входные данные мероприятия и получает готовую финансовую модель.

Проект демонстрирует использование электронных таблиц не только для хранения данных, но и для построения автоматизированного прикладного инструмента с бизнес-логикой, справочниками, внешними данными и контролем качества результата.
